# README设计依据

Audience: 使用Codex等coding agent复刻组件的开发者。
Value: 从截图、视频或URL，交付有状态与动效对照的可编辑组件。
Proof: 本仓库真实的组件源码、可运行用例、参考/复刻完整录像和余差记录。
First action: 安装skill，再提供参考URL；或启动cases/ui-lab。
Visual theme: 白色画布、深色正文、中性细线；以实际组件画面作为证据。

README采用真实截图与可搜索的Markdown；没有生成装饰封面或动图。遵循beautify-github-readme的方法组织价值、案例、使用与边界。
