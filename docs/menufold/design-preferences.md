# MenuFold 组件实验库的视觉依据

适用范围：本批15个React组件与其比较图库，不是MenuFold产品的全局品牌规范。

用户指定的是各来源组件模式及固定Dock、即时Tabs、业务受控等取舍。2026-10-30反馈“整体颜色的设置没有做好”。此前统一暖灰/橄榄绿是实现时的自行选择，不是用户认可的品牌色；原动效复查把配色列为既定适配的结论在此更正。

当前实现决定：按每个实际参考恢复角色色板，保留其强调色和状态色；图库使用中性白/灰背景，不给被比较组件染色。图标内容与业务布局仍遵循先前明确的适配。没有新增全局主题系统或暗色产品方案。

- 图库参数：`src/batch.css` 的 `--lab-*`；外层页面与研究导航限定在 `src/app.css` 的 `data-surface="component-gallery"`。
- 各组件参数：`src/components/<slug>.css` 中的作用域样式/颜色变量；独立registry安装应得到同一配色。
- 内容示例的图形颜色：`src/batch/<slug>/study.css`；与实际组件色板共同对照，不从别的项目套用配色。
- 数值来源、状态截图及余差：`notes/menufold-color/` 与 `evidence/batch/<slug>/color-review/`。参考未展示的本地业务状态由实现者明确选定并记录。

用户未要求改变字体、密度或已修正的动效，本轮保留这些行为。
