# Stacked Empty State 动效复查

2026-10-30 完成。源码已冻结；保留三种原生图标、紧凑卡片和单个主要操作的产品取舍。

## 修复

- 旧版从18°倾斜和0.92缩放起步，按左/中/右延迟，与原版中心先出现、两侧从直立扇出的次序不符。改为中心先入场，两侧延后100ms；位移与旋转使用300/22的弹簧拟合，最终仍为±10°。
- 旧版入场 delay 同时控制 hover，右卡反应约130ms。scale 现在独立、无入场延迟；三卡实际采样约11–13ms开始响应，保留1.02的轻微放大，不添加额外抬升、旋转或移动光晕。
- 切换 Rules/Groups/Stash 原来会重建卡片、重复整组入场。卡片保持身份，仅显式 Replay 重播入场。
- 补根元素 border-box，独立安装的390px容器不溢出。

## Skill 经验与余差

将首次入场、hover和反向分别分配时序；不要把初次stagger带到每次交互。复查内容更新时是否不必要地重建整组表面。原生图标替代网页缩略图是明确取舍，入场顺序错误不是。

仍保留紧凑矩形、原生SVG、暖色纸面、不同阴影大小和单操作布局；原版照片的下缘渐隐不适用于该图标绘制。弹簧参数为拟合，中心过冲幅度不同，不声称1:1。原版移动端与隐藏变体未检查。
