# Segmented Control 视觉规格

依据 default.jpg、最新 contact-sheet.jpg 与73帧 sequence.json。尺寸按480×304原图估读，色值为复刻近似值。

**布局。** 背景约#fafafa；白卡位于(28,22)，约440×262，圆角11px，淡边框和下缘阴影。内边距20px。三组纵排，标题间距约82px，以近白细线分隔；标题距控件约8px。首行高28px，按钮间距8px、水平内边距10px；次行高24px。

**字体。** 中性紧凑的无衬线；标题约12px、#888，正文13–14px、#555，选中文字近#171717、略重。图标约12px，细描边，距文字5px。通知数字为浅灰小徽标；优惠徽标淡蓝紫底、蓝灰字。

**三种选中态。** Dashboard是分离按钮：选中项约#f0f0f0、圆角6px，其余白底淡描边。Layout是约215px宽的浅灰圆角轨道，选中项为白色滑块，带细边和微弱阴影，各段随内容定宽。Billing无填充，用1–2px灰色下划线；Yearly的线包含优惠徽标范围，宽约110px。

**位移与形变。** 1618ms仍选Analytics；1686ms通知底块左缘尚偏左，呈横向拉宽，1800–1884ms趋于贴合目标。Calendar在3449–3633ms间白块右移、边缘逐渐收敛。文字、图标和轨道基本固定，变化集中在底块位置与宽度；未见明确竖向弹跳或文字拉伸。Analytics从701ms展示帧起已选中，未捕获完整移动过程。

**限制。** 平均约72ms采样，时间标记不能当作点击后的精确延迟。无法反推原始曲线、弹簧参数、准确时长，或确认微小过冲、淡入淡出及共享元素机制。拼图没有Billing切换过程。精确字体、色值及悬停／焦点反馈也无法确认。
